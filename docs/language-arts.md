# Language Arts

Grade 5 language arts practice. Each question picks one of five practice versions at
random, so **Reset / Randomize** gives a fresh set of problems for another try. Use
**Check** on a question or **Check All** for a score; an answer can be shown after
five wrong tries.

## [Test 4 — Quarter Exam](quizzes/la_042_test_4.html)

**Lesson 42.** Kinds of sentences, clauses, plural nouns, simple/compound/complex
sentences, principal parts of verbs, kinds of verbs, subjects and predicates, and
subject-verb agreement.
