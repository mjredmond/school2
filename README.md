# school2

Interactive practice quizzes for math, language arts, and history, published as a
MkDocs site.

**Site:** https://mjredmond.github.io/school2/

## Layout

```
docs/
  index.md          generated by deploy.py — do not edit by hand
  math.md           hand-written subject pages
  language-arts.md
  history.md
  quizzes/          the quiz HTML files, served as-is
mkdocs.yml
deploy.py           regenerates the index, builds, and deploys
```

## Adding a quiz

1. Copy the HTML file into `docs/quizzes/` using the naming convention:

   ```
   <subject>_<lesson>_<type>_<number>.html
   ```

   where subject is `math`, `la`, or `history` — for example
   `math_162_quiz_33.html` or `history_160_test_11.html`. The lesson number is
   optional for material not tied to a lesson.

2. Run `python deploy.py`. The index page picks up the new file automatically.
   If the auto-generated link text needs to read differently, add an entry to
   `LABEL_OVERRIDES` in `deploy.py`.

3. Optionally add a description to the matching subject page.

4. Commit and push the source changes.

## Deploying

```bash
pip install -r requirements.txt

python deploy.py            # regenerate index, build, and push to gh-pages
python deploy.py --serve    # preview locally at http://localhost:8000
python deploy.py --build    # build only, no deploy
python deploy.py --index    # regenerate the index only
```

`deploy.py` pushes the *built* site to the `gh-pages` branch. Commit and push your
source changes to `main` separately.

GitHub Pages must be set to serve from the `gh-pages` branch (root) under
**Settings → Pages**.
